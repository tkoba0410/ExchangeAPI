# ApiCredentials メモ

API キー/シークレットの表現と運用例。

## フィールド
- `ApiKey` / `ApiSecret`: 必須。
- `KeyType` (任意): 権限種別を表現（例: `"read"`, `"trade"`, `"withdraw"`）。
- `ExpiresAt` (任意): 失効時刻。未設定の場合は無期限を想定。

## 運用パターン
- 取引所が複数権限のキーを発行する場合、`KeyType` で種別を明示し、実行前に適切なキーを選択する。
- ローテーション時は旧鍵の `ExpiresAt` を設定して呼び出し側で切替タイミングを判定できるようにする。
- `IApiCredentialProvider` 実装はスレッドセーフを前提とし、キャッシュ/期限切れチェックの責務を持つ。

## セキュリティ注意
- テストやログに鍵を残さない。`ToString` をオーバーライドせず、構造化ログは鍵を含めない。
