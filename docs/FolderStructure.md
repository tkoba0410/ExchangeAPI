# フォルダ構成の正本（docs を正とする）と src/test への適用

## 目的

本ドキュメントは、本リポジトリにおける **全体のフォルダ構成を決定する唯一の文書**である。

* `/docs` 配下の現在のフォルダ構造を **正（canonical）** とする
* 同一構造を **`/src` と `test/` にそのまま適用（ミラー）**する
* 層（レイヤ）間が **横断的に参照し合う**ことを想定した構成とする（＝参照関係をフォルダ境界で制限しない）

本ドキュメントは「どの層が何を参照してよいか」を品質評価として裁定しない。
ここで決めるのは **どこに何を置くか（場所の一貫性）**のみである。

---

## 決定事項（Invariants）

### 1. docs が構成の正本（Source of Truth）

* **フォルダ階層（ディレクトリ構造）の定義は `/docs` が正本**である
* `/src` と `/test` は `/docs` の構造を機械的に写した **投影（projection）**である

### 2. src と test は docs を完全ミラーする

* `/src` と `/test` のディレクトリ階層は **`/docs` と一致**しなければならない
* `docs/X/Y/...` が存在するなら、`src/X/Y/...` と `test/X/Y/...` も同じ階層を持つ
* 逆に、`src` または `test` に新しい層（ディレクトリ）を追加する場合は、**必ず `docs` にも同階層を追加**する

### 3. 層の横断参照を前提とする

* ある層のコードが別の層のコードを参照することは **許容**する
* 参照関係の善し悪しは本ドキュメントの対象外（設計判断・品質評価に踏み込まない）
* ただし、参照を許容する代わりに **場所（path）だけは不変**とする
  → 「参照が増えても、どこに何があるかが失われない」ことを優先する

## 正式なフォルダ構造（Canonical Tree）

以下を `/docs` の現状構造として正とし、`/src` と `/test` に同形で適用する。

```
Common/
  Contracts/
  Transport/
Composition/
  Factory/
Core/
Exchanges/
  Adapter/
  Raw/
  exchange-design/
  Bitflyer/
    Adapter/
    Raw/
  Bittrade/
    Adapter/
    Raw/
```

※ 上記ツリーは「フォルダ構成の決定」であり、ファイル名や実装詳細は別文書・別正本に委ねる。

---

## src/test への適用規約

### ルート規約

* `docs/<path>` に対応するコード配置先は次の通りとする

| docs              | src              | test              |
| ----------------- | ---------------- | ----------------- |
| `docs/<path>/...` | `src/<path>/...` | `test/<path>/...` |

### 例

* `docs/Common/Contracts/README.md` に対応するコード群は

  * `src/Common/Contracts/...`
  * `test/Common/Contracts/...`

* `docs/Exchanges/Bitflyer/Raw/...` に対応するコード群は

  * `src/Exchanges/Bitflyer/Raw/...`
  * `test/Exchanges/Bitflyer/Raw/...`

---

## 変更ルール（構造の変更）

構造（フォルダ階層）を変更する場合は、必ず次を同一PRで行う。

1. `/docs` のツリーを更新（＝正本の更新）
2. 同じ更新を `/src` と `/test` に反映（＝投影の更新）
3. 変更したディレクトリの `README.md` が存在する場合は、意味定義が破綻していないことを確認する
   （意味の更新が必要なら当該 README も更新する）

---

## 位置づけ

* 本ドキュメントは **フォルダ構造（場所）**の唯一の決定文書である
* 各ディレクトリが「何を意味するか」「何が正本か」は、原則として当該ディレクトリ配下の `README.md` が定義する
* 文書とコードの整合性ルール（頂点文書）は `docs/README.md` を参照する
