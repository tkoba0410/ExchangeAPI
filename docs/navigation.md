# Navigation Terms (Non-Normative)

本書は、人間向けの理解およびナビゲーションを目的とした **Non-Normative 文書**である。

本書に記載された用語・分類・呼称は以下を保証しない。

* 正確性
* 網羅性
* 一意性
* 長期的な安定性

本書の内容は、実装、テスト、互換性判断、仕様解釈に影響を与えてはならない。

## Scope

本リポジトリでは、Wire〜Adapter 層において
API を意味分類（MarketData / Trading 等）で整理しない。
Public / Private のみを物理分離の基準とする。

本書に記載される用語は、特定の EndpointId を識別・代替・一意化するものではない。
複数の EndpointId を指し得る概念的・慣例的呼称を含み得る。

本書の内容は、EndpointId の定義、解釈、同一性判断に影響を与えてはならない。
