# Revision History

本書は、リリース後の変更履歴を記録する正本である。
設計規範の正本は `docs/normative/*` を優先する。

---

## Entry Format

```md
## <Version> - <YYYY-MM-DD>
- Type: Breaking | Non-breaking | Docs | Process
- Scope: <Contracts/Boundary/Inventory/...>
- Summary: <変更要約>
- Impact: <利用者影響>
- Migration: <移行要否。不要なら "None">
- References: <PR / issue / related docs>
```
