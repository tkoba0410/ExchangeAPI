# Release Notes v2.1.0

## Highlights

- Added `ExchangeApi.Optional.Logging` for optional, secret-safe logging utilities.
- Added safe redaction helpers for known credential keys, auth headers, signatures, and configured sensitive values.
- Added evidence run directory helpers for the standard `local/evidence/<phase>/<yyyymmdd>-<label>/` layout.
- Added JSONL file logging with redaction applied before writing.
- Expanded MCP Server read-only inspection surface:
  - `get_collateral_accounts`
  - `get_balance_history`
  - `get_collateral_history`
  - `get_child_orders`

## Compatibility

- No package / project consolidation is included in v2.1.0.
- Venue package consolidation remains a v3 candidate.
- Existing facade / factory API names remain unchanged.
- CLI evidence options are not included in v2.1.0.
- No `docs/plan-v3.0.0.md` is added in v2.1.0.

## Safety

- API key, API secret, signatures, and Authorization headers must not appear in logs, evidence, MCP results, exceptions, or stderr diagnostics.
- MCP state-changing operations remain out of scope.

## MCP Response Shape

- `get_collateral_accounts`: `accounts` array
- `get_balance_history`: `items` array
- `get_collateral_history`: `items` array
- `get_child_orders`: `orders` array
- Inspection responses do not include `venue` or `accountContext`.
