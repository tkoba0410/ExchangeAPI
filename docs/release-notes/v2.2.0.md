# Release Notes v2.2.0

## Highlights

- Fixed `v2.2.0` as an operational / verification release.
- Added `docs/release-checklist-v2.2.0.md`.
- Strengthened local consumer smoke to restore and use `ExchangeApi.Optional.Logging`.
- Added GitHub Packages consumer smoke script.
- Added release asset helper for CLI / MCP executable assets and SHA-256 checksums.
- Added MCP inspection live verification runbook.
- Added release evidence runbook.

## Compatibility

- No public API breaking change is included in v2.2.0.
- No package / project consolidation is included in v2.2.0.
- `Unified`, `ExchangeApi.Optional.Resilience`, credentials provider expansion, full MCP client, and MCP write tools remain out of scope.
- Package / project consolidation remains a v3.0.0 candidate.

## Verification

- `dotnet test ExchangeApi.slnx --no-restore`
- `bash scripts/pack-local-nuget.sh 2.2.0-local.checklist`
- `bash scripts/smoke-local-nuget-consumer.sh 2.2.0-local.checklist`
- `bash scripts/create-release-assets.sh 2.2.0-local.checklist linux-x64 Release`
- `dotnet test ExchangeApi.LiveTests.slnx --no-restore`

## Safety

- Default scripts do not create evidence / logs unless explicitly invoked.
- Evidence helper integration is limited to scripts / verification.
- Credentials, API keys, API secrets, signatures, and Authorization headers must not appear in evidence, logs, results, exceptions, stdout, or stderr.
- MCP state-changing operations remain out of scope.
