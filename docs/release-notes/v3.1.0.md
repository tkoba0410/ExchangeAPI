# Release Notes v3.1.0

## Highlights

- Added bitFlyer public Realtime API read MVP.
- Added typed streams for ticker, executions, board snapshot, and board delta.
- Added `BitflyerRealtimeClientFactory.CreatePublicClient(...)`.
- Added `IBitflyerPublicRealtimeClient`.
- Added `BitflyerRealtimeChannels` channel name helpers.

## Compatibility

- Existing HTTP endpoint contracts are unchanged.
- Existing facade, factory, and endpoint public API names are preserved.
- Realtime API is separate from the HTTP endpoint matrix.
- Realtime API is included in the existing `ExchangeApi.Exchanges.Bitflyer` package.
- No new layer-specific venue packages are introduced.

## Public API

The primary public API is `IAsyncEnumerable<T>` based.

```csharp
await using var client = BitflyerRealtimeClientFactory.CreatePublicClient();

await foreach (var ticker in client.SubscribeTickerAsync(ProductCodes.BtcJpy, cancellationToken))
{
    Console.WriteLine(ticker.Ltp);
}
```

Supported v3.1.0 streams:

- `SubscribeTickerAsync(...)`
- `SubscribeExecutionsAsync(...)`
- `SubscribeBoardSnapshotsAsync(...)`
- `SubscribeBoardDeltasAsync(...)`

## Non-Scope

v3.1.0 does not include:

- private realtime
- Binance realtime
- `Unified` realtime abstraction
- full order book state builder
- automatic reconnect / backoff
- Reactive Extensions / `System.Reactive`
- `IObservable<T>` public API
- CLI / MCP production integration
- order / cancel / deposit / withdraw operations
