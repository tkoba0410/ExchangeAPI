# Release Notes v3.2.0

## Highlights

- Hardened bitFlyer public Realtime API lifecycle behavior.
- Added best-effort unsubscribe when typed realtime streams end.
- Added representative sample payload tests for ticker, executions, board snapshot, and board delta.
- Added bitFlyer Realtime getting started guide.
- Added bitFlyer Realtime live verification runbook.
- Added venue onboarding guide for future new venue public read MVP work.

## Compatibility

- Existing HTTP endpoint contracts are unchanged.
- Existing bitFlyer Realtime public API names are preserved.
- Realtime API remains separate from the HTTP endpoint matrix.
- No new venue package is introduced in v3.2.0.
- No layer-specific venue packages are introduced.

## Non-Scope

v3.2.0 does not include:

- private realtime implementation
- Binance realtime
- new venue implementation
- `Unified` implementation
- full order book state builder
- automatic reconnect / backoff
- Reactive Extensions / `System.Reactive`
- `IObservable<T>` public API
- order / cancel / deposit / withdraw operations

Private realtime remains a v3.3.0-or-later candidate and is documented only as a design note.

## Safety

- Live tests skip safely without opt-in.
- Public realtime live verification does not require credentials.
- No credentials, API keys, API secrets, signatures, or Authorization headers should appear in evidence, logs, results, exceptions, stdout, or stderr.
