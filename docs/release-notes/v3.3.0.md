# Release Notes v3.3.0

## Highlights

- Added bitFlyer private realtime read MVP.
- Added private realtime `auth` request support using `IApiCredentialSession.Sign(payload)`.
- Added typed streams for `child_order_events` and `parent_order_events`.
- Added venue-specific private realtime event DTOs.
- Added deterministic tests for auth request shape and private event decoding.
- Added private realtime live verification runbook.
- Documented v3.x as the bitFlyer Realtime API maturity track.

## Compatibility

- Existing HTTP endpoint contracts are unchanged.
- Existing bitFlyer public realtime API names are preserved.
- Realtime API remains separate from the HTTP endpoint matrix.
- Main realtime public API remains `IAsyncEnumerable<T>`.
- No `IObservable<T>` public API is introduced.
- No `System.Reactive` dependency is introduced.

## Non-Scope

v3.3.0 does not include:

- order / cancel / deposit / withdraw operations
- Binance realtime
- `Unified` implementation
- automatic reconnect / backoff / resubscribe
- full order book state builder
- private order state builder
- Reactive Extensions / `System.Reactive`
- `IObservable<T>` public API
- credentials provider expansion
- CLI / MCP full integration

Rx integration remains an optional package candidate such as `ExchangeApi.Optional.Reactive`.
Reconnect / state builder work remains a v3.4.0-or-later realtime maturity candidate.

## Migration

No migration is required for existing HTTP or public realtime users.

New private realtime read users should reference `ExchangeApi.Exchanges.Bitflyer` and create a private realtime client with an `IApiCredentialProvider`:

```csharp
await using var client = BitflyerRealtimeClientFactory.CreatePrivateClient(credentialProvider);
```

## Safety

- Live tests skip safely without opt-in.
- Private realtime live verification is opt-in only.
- API secret is not exposed through public API.
- No credentials, API keys, API secrets, signatures, or Authorization headers should appear in evidence, logs, results, exceptions, stdout, or stderr.
