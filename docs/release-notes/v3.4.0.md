# Release Notes v3.4.0

## Highlights

- Added lifecycle-aware bitFlyer realtime stream envelope APIs.
- Added `Subscribe*StreamAsync(...)` APIs alongside existing DTO-only `Subscribe*Async(...)` APIs.
- Added reconnect / backoff / resubscribe foundation for envelope streams.
- Added private realtime authentication replay after reconnect.
- Added `ContinuityLost` lifecycle events so consumers can detect possible stream gaps.
- Added `MessageRejected` events for decode failures without exposing raw payloads or secrets.
- Added `BitflyerRealtimeException.Kind` for controlled restart decisions.
- Added deterministic tests for public and private reconnect event order.

## Compatibility

- Existing HTTP endpoint contracts are unchanged.
- Existing bitFlyer realtime DTO-only API names are preserved.
- DTO-only realtime APIs remain `IAsyncEnumerable<T>` and do not emit lifecycle events.
- Realtime API remains separate from the HTTP endpoint matrix.
- No `IObservable<T>` public API is introduced.
- No `System.Reactive` dependency is introduced.

## Stream Envelope

Envelope APIs return `IAsyncEnumerable<BitflyerRealtimeStreamEvent<T>>`.

Public reconnect order:

```text
Reconnecting
Reconnected
Resubscribed
ContinuityLost
Data...
```

Private reconnect order:

```text
Reconnecting
Reconnected
AuthenticationReplayed
Resubscribed
ContinuityLost
Data...
```

Gap-free continuity is not guaranteed after reconnect.
Consumers should treat `ContinuityLost` as a signal to resync or restart if their use case requires stronger continuity.

## Non-Scope

v3.4.0 does not include:

- order / cancel / deposit / withdraw operations
- Binance realtime
- `Unified` implementation
- full order book state builder
- private order state builder
- Reactive Extensions / `System.Reactive`
- `IObservable<T>` public API
- optional realtime state package
- CLI / MCP full integration

Rx integration remains an optional package candidate such as `ExchangeApi.Optional.Reactive`.
State builders remain v3.5.0-or-later realtime maturity candidates.

## Migration

No migration is required for existing HTTP, public realtime, or private realtime DTO-only users.

Users that need lifecycle events can opt into the new stream envelope APIs:

```csharp
await foreach (var item in client.SubscribeTickerStreamAsync(ProductCodes.BtcJpy, cancellationToken))
{
    if (item is BitflyerRealtimeData<BitflyerRealtimeTickerMessage> data)
    {
        Console.WriteLine(data.Value.Ltp);
    }
}
```

## Safety

- Live tests skip safely without opt-in.
- Private realtime live verification is opt-in only.
- API secret is not exposed through public API.
- `MessageRejected` does not include raw payloads.
- No credentials, API keys, API secrets, signatures, or Authorization headers should appear in evidence, logs, results, exceptions, stdout, or stderr.
