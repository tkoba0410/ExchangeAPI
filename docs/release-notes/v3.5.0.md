# Release Notes v3.5.0

## Highlights

- Added Realtime Diagnostics Foundation for bitFlyer realtime envelope streams.
- Added public `RealtimeDiagnosticEvent` contract.
- Added `RealtimeDiagnosticEventTypes` and `RealtimeDiagnosticSeverities` constants.
- Added `BitflyerRealtimeDiagnostic<T>` envelope event.
- Added diagnostic events for subscription, raw frame receipt, message decode, message rejection, reconnect, resubscribe, and continuity loss.
- Added raw frame metadata to realtime channel messages.
- Added `ExchangeApi.Optional.Logging.Realtime` raw frame log record helper.
- Added opt-in raw frame body logging support with per-frame size limits.

## Compatibility

- Existing HTTP endpoint contracts are unchanged.
- Existing DTO-only realtime APIs remain unchanged.
- Existing stream envelope APIs remain `IAsyncEnumerable<BitflyerRealtimeStreamEvent<T>>`.
- Stream envelope consumers may now receive `BitflyerRealtimeDiagnostic<T>` events.
- No `IObservable<T>` public API is introduced.
- No `System.Reactive` dependency is introduced.

## Diagnostics

`RealtimeDiagnosticEvent` is a public diagnostics contract for stream lifecycle and message handling.
It intentionally does not model market data semantics, account state, order state, or Unified behavior.

`EventType` and `Severity` are strings with official constants:

```text
RealtimeDiagnosticEventTypes
RealtimeDiagnosticSeverities
```

External market data and internal diagnostic data share the same envelope stream as distinct event types.
DTO-only APIs remain available for consumers that only need market data.

## Raw Frame Logging

Raw frame body logging is opt-in.
Default behavior does not create logs or evidence.

When enabled through `ExchangeApi.Optional.Logging`, raw frame body logging is constrained by:

- 1 received frame = 1 JSONL record
- per-frame `maxRawFrameBodyBytes`
- oversized bodies are skipped, not truncated
- disabled / oversized / redaction-failed bodies are recorded as skipped metadata
- private auth payloads are not saved

File output, JSONL, evidence layout, and human-readable logs remain `ExchangeApi.Optional.Logging` responsibilities.

## Non-Scope

v3.5.0 does not include:

- stream replay implementation
- fake transport / scenario helper optional package
- Reactive Extensions / `System.Reactive`
- `IObservable<T>` public API
- `ExchangeApi.Optional.Realtime.Resilience`
- state builder / state projection
- HTTP + realtime state coordination
- Binance realtime
- venue-wide realtime abstraction
- Unified realtime abstraction
- order / cancel / deposit / withdraw operations

## Migration

No migration is required for DTO-only realtime users or HTTP users.

Consumers of `Subscribe*StreamAsync(...)` should handle or ignore `BitflyerRealtimeDiagnostic<T>` events:

```csharp
await foreach (var item in client.SubscribeTickerStreamAsync(ProductCodes.BtcJpy, cancellationToken))
{
    if (item is BitflyerRealtimeData<BitflyerRealtimeTickerMessage> data)
    {
        Console.WriteLine(data.Value.Ltp);
    }
    else if (item is BitflyerRealtimeDiagnostic<BitflyerRealtimeTickerMessage> diagnostic)
    {
        Console.WriteLine(diagnostic.Diagnostic.EventType);
    }
}
```

## Safety

- Live tests skip safely without opt-in.
- Default library usage does not create file logs or evidence.
- Raw frame body logging is opt-in.
- Oversized raw frame bodies are skipped and not truncated.
- API keys, API secrets, signatures, Authorization values, private auth payloads, and raw credential profiles must not appear in evidence, logs, results, exceptions, stdout, or stderr.
