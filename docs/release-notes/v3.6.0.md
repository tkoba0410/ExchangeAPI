# Release Notes v3.6.0

## Highlights

- Added `ExchangeApi.Optional.Testing`.
- Added `RealtimeReplayFrame` as the raw frame replay input model.
- Added `RealtimeReplayResult<T>` as the replay result model.
- Added `BitflyerRealtimeReplayRunner` for bitFlyer public realtime raw frame replay.
- Added deterministic replay coverage for ticker, executions, board snapshot, and board delta raw frames.
- Added malformed ticker payload replay coverage.
- Added a bitFlyer public realtime sample payload catalog for deterministic replay tests.
- Updated local and GitHub Packages consumer smoke scripts to verify `ExchangeApi.Optional.Testing`.

## Compatibility

- Existing HTTP endpoint contracts are unchanged.
- Existing realtime DTO-only APIs are unchanged.
- Existing realtime stream envelope APIs are unchanged.
- Existing `ExchangeApi.Optional.Logging` APIs are unchanged.
- No `System.Reactive` dependency is introduced.
- No `IObservable<T>` public API is introduced.

## Optional Testing

`ExchangeApi.Optional.Testing` is a small optional package for ExchangeAPI-layer realtime replay / decode / diagnostic testing.

The v3.6.0 public surface is intentionally limited to:

```text
RealtimeReplayFrame
RealtimeReplayResult<T>
BitflyerRealtimeReplayRunner
```

The package is fixture-first.
Repository sample payload fixtures and in-memory `RealtimeReplayFrame` values are the primary inputs.
JSONL log replay is not a v3.6.0 feature.

## Non-Scope

v3.6.0 does not include:

- `ExchangeApi.Optional.Reactive`
- Reactive Extensions / `System.Reactive`
- `IObservable<T>` public API
- JSONL log replay
- simulation framework
- Gateway / Platform behavior testing
- strategy logic testing
- order lifecycle model
- ledger / position model
- state reconstruction
- Binance realtime
- venue-wide realtime abstraction
- Unified realtime abstraction
- order / cancel / deposit / withdraw operations

## Migration

No migration is required for existing HTTP users, realtime users, or optional logging users.

Consumers that want deterministic bitFlyer realtime replay tests can add:

```text
ExchangeApi.Optional.Testing
```

The package is optional and is not required by core, venue, credentials, or logging packages.

## Safety

- Live tests skip safely without opt-in.
- Default library usage does not create file logs or evidence.
- Sample payload fixtures must not contain credentials, signatures, Authorization values, raw credential profiles, or account detail.
- API keys, API secrets, signatures, Authorization values, private auth payloads, and raw credential profiles must not appear in evidence, logs, results, exceptions, stdout, or stderr.
