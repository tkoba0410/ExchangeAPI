# Release Notes v3.7.0

## Highlights

- Added `ExchangeApi.Optional.Reactive`.
- Added `ToObservable<T>(this IAsyncEnumerable<T> source)`.
- Added deterministic tests for the reactive adapter contract.
- Updated local and GitHub Packages consumer smoke scripts to verify `ExchangeApi.Optional.Reactive`.

## Compatibility

- Existing HTTP endpoint contracts are unchanged.
- Existing realtime DTO-only APIs are unchanged.
- Existing realtime stream envelope APIs are unchanged.
- Existing optional credentials, logging, and testing APIs are unchanged.
- Core and venue packages still expose `IAsyncEnumerable<T>` as the primary realtime API.
- `System.Reactive` is only referenced by `ExchangeApi.Optional.Reactive`.

## Optional Reactive

`ExchangeApi.Optional.Reactive` is a thin generic adapter from `IAsyncEnumerable<T>` to `IObservable<T>`.

The v3.7.0 public surface is intentionally limited to:

```text
ToObservable<T>(this IAsyncEnumerable<T> source)
```

Semantics:

- returned observable is cold
- each subscription re-enumerates the source
- subscription disposal cancels source enumeration
- normal source completion calls `OnCompleted`
- source exception calls `OnError`
- disposal / cancellation sends no terminal notification
- DTO-only items and stream envelope events are forwarded as `OnNext`
- stream item meaning is not interpreted

## Secret Neutrality

`ExchangeApi.Optional.Reactive` does not inspect, serialize, log, redact, or persist stream items.
It does not create evidence or write to stdout / stderr.
It does not handle credentials, tokens, signatures, or Authorization values.

Secret-free behavior still depends on the source contract and the consumer's observer / logging implementation.

## Non-Scope

v3.7.0 does not include:

- venue-specific reactive helper
- envelope-specific helper
- `WhereData` / `WhereDiagnostic`
- options type
- scheduler overload
- buffering
- retry / reconnect / backoff
- stream health operator
- lifecycle / contract hardening
- state reconstruction
- simulation framework
- Gateway / Platform behavior
- Binance realtime
- venue-wide realtime abstraction
- Unified realtime abstraction
- order / cancel / deposit / withdraw operations

## Migration

No migration is required for existing HTTP users, realtime users, optional logging users, or optional testing users.

Consumers that want Rx integration can add:

```text
ExchangeApi.Optional.Reactive
```

The package is optional and is not required by core, venue, credentials, logging, or testing packages.

## Safety

- Live tests skip safely without opt-in.
- Default library usage does not create file logs or evidence.
- `ExchangeApi.Optional.Reactive` does not inspect or stringify stream items.
- API keys, API secrets, signatures, Authorization values, private auth payloads, and raw credential profiles must not appear in evidence, logs, results, exceptions, stdout, or stderr.
