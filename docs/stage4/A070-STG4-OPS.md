# A070-STG4-OPS Stage4 動作確認・運用メモ

## 1. 前提設定
- API キー/シークレット、product_code（例: BTC_JPY）を設定
- Stage3 までのビルド/テストが緑であること

## 2. 動作確認の代表手順
1) LIMIT 注文送信 → `child_order_acceptance_id` を取得  
2) STOP 注文送信（trigger_price 指定）  
3) キャンセル（cancelchildorder）で指定注文を取り消し  
4) 全キャンセル（cancelallchildorders）で残注文を全て取り消し  
5) positions/executions/collateral を取得し、注文が反映されていることを確認  
6) 429/400/403 など代表的なエラーを発生させ、E2 例外で分類されることを確認  

## 3. 運用メモ
- レートリミット: 429 応答時の挙動をログに残し、フックで必要に応じて待機/リトライを実装する
- タイムアウト: RestClient のタイムアウト値と再試行方針を設定で管理
- ログ/メトリクス: E2 エラーコードと HTTP ステータスを併せて記録し、運用時の診断を容易にする
